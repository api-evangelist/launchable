# Launchable (CloudBees Smart Tests)

> Launchable is a software development intelligence platform for continuous integration. It applies
> machine learning to a team's CI and test history to return a prioritized subset of tests most
> likely to fail for a given change, so a suite can be run in a fraction of the time while keeping
> most of its failure-detection power. It also provides test suite parallelization, unhealthy/flaky
> test detection, trends and reporting, and Slack and GitHub notifications. The service is consumed
> through a first-party open-source CLI rather than a published REST reference. Launchable was
> founded by Jenkins creator Kohsuke Kawaguchi and is now part of CloudBees, where the product
> ships as CloudBees Smart Tests.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from this repository's apis.yml
and artifacts. Launchable publishes no llms.txt of its own (https://help.launchableinc.com/llms.txt
returns 404); the operator CloudBees publishes one at https://www.cloudbees.com/llms.txt.

## APIs

- [Launchable API](https://help.launchableinc.com/resources/cli-reference/): Records builds, test
  sessions, test results and attachments, and returns predictive test subsets and parallel splits.
  Base URL https://api.mercury.launchableinc.com (overridable via LAUNCHABLE_BASE_URL; a stable-IP
  host https://api-static.mercury.launchableinc.com is documented for restricted networks). No
  public REST reference, OpenAPI, GraphQL or AsyncAPI document is published.

## Authentication

- API key in the LAUNCHABLE_TOKEN environment variable, issued per workspace from the web app.
- GitHub OIDC for keyless authentication from GitHub Actions.
- Verify with `launchable verify`.
- Detail: [authentication/launchable-authentication.yml](authentication/launchable-authentication.yml)
